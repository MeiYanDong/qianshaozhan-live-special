# 前哨站 · 每周直播档案

静态阅读页，收录已处理的小鹅通直播：

- 2026.6.21 一次带案例的 AI 心法分享（上）
- 2026.6.28 一次带案例的 AI 心法分享（下）
- 2026.9.12 关于今年看过的最重要的视频

页面包含回放链接、阅读整理稿、可阅读逐字稿和重点理念摘编。内容来自本地 ASR 与人工轻整理产物，不包含签名 HLS 或临时下载地址。

## 内容组织

首页按日期倒序列出已收录直播，支持主题筛选与标题、主题、摘要搜索。每场直播独立成一期；主题可多选，系列可选。AI 心法分享的上下篇属于同一系列，强生理念是 2026-09-12 这一期的摘编。

`episodes.js` 管理期目元数据。添加一期时，将稿件放入 `content/`，再增加一条包含唯一 `id`、ISO 日期、标题、主题、时长、回放链接和稿件路径的记录。`rating` 仅填写用户明确给出的星级；`series` 和 `highlights` 按实际内容填写。没有收录的周次不补造期号。

每期链接使用 `#/episode/<id>/notes`，逐字稿为 `transcript`，摘编使用其独立 `id`。章节链接在末尾追加 `/chapter-N`。Hash 路由可直接在 GitHub Pages 打开和刷新，无需服务器重写。返回目录保留当前页面会话内的筛选条件。

## 本地预览

在本目录运行 `python3 -m http.server 8071`，访问 `http://localhost:8071`。部署为纯静态 GitHub Pages，不需要构建或运行后端。

## 前端依赖

依赖随站点保存在 `assets/vendor/`，页面运行不请求外部 CDN：

- Marked 15.0.12：Markdown 解析。
- DOMPurify 3.4.15：清洗解析后的 HTML。
- Lucide 0.468.0：界面图标。

许可证随对应文件保留。原始 Markdown 完整保留；阅读界面将重复标题、回放链接及推荐元数据统一放在阅读页头部。正文中的数字与指标不做删减。
